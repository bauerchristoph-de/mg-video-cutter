# AI Video-Cutter

Rohvideo rein → fertiges, publizierbares Social-Media-Video raus: geschnitten, Karaoke-Untertitel, animierte Highlight-Captions im eigenen CI, Sound-Effekte, gemasterter Ton.

**Erster Start:** „Richte den Video-Cutter ein“ — das Plugin führt Setup-Interview und Marken-Analyse durch und legt den lokalen Kundenordner an (Config, Markenprofil, Learnings). Alles Kundenspezifische bleibt lokal; das Plugin selbst wird zentral gepflegt und aktualisiert.

**Alltag:** Video in `rohmaterial/` legen → „Mach mir daraus ein Reel für Instagram“ → Briefing-Rückfrage → Schnittplan-Freigabe → fertiges Video + Caption in `fertig/`.

Voraussetzungen: ffmpeg auf dem Rechner, Python 3, verbundener Arbeitsordner.
